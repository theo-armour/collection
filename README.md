# Theo Armour / Collection

A GitHub repository intended to be the starting point for an extensive collection of personal and family "things".

## Purpose

* Document the process of creating a template and enabling of online collections
* Serve as a central hub for managing and organizing the collection.
* Act as a repository from which the material 
* Act as a catalog for links to the collected items in other locations
* Provide a structured and searchable archive of the collection.
