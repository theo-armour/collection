## First principles

Given: https://en.wikipedia.org/wiki/Respect_des_fonds

AI> The principle of "respect des fonds" is fundamental in archival science, emphasizing that records should be kept according to their origin and original order, which is crucial for maintaining the context and authenticity of genealogical research.

Theo mostly> If you're doing an archive of an organization, then the available sources are usually best organized and viewed in an org chart. If you're looking at a family history, then the genealogy provides a good basis for figuring out the _fonds_ (sources). A genealogy tree helps to trace the lineage and relationships within the family, which in turn informs how the records should be grouped and maintained.

There are a number of excellent web apps for entering, maintaining, and sharing genealogies.

* [Geni.com](https://www.geni.com)
* [Ancestry.com](https://www.ancestry.com)
* [MyHeritage.com](https://www.myheritage.com)
* [FamilySearch.org](https://www.familysearch.org)

There are several issues:

* You generally need to have a username and password to get in and view any of the data in any detailed manner.
* The user interface can get very tricky because there is so much data.
* A single app is trying to do genealogy plus biography in the same app.
* If you want to do anything significant with them, you have to pay.

## Theo Armour / Genealogy

https://theo-armour.github.io/genealogy/#README.md

This is an online family biography viewer. It's still a beginning, but the idea is to generally follow the principles of Wikipedia articles for notable people.

It should be well referenced with links to authoritative articles.

The files are simple Markdown files.

It should run on any static server, such as GitHub Pages.

It should be open source and readily available on GitHub.

The code should be easy-peasy and readable by a person that knows a minimum amount of JavaScript.
